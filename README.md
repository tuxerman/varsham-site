# Varsham

A Malayalam calendar. For each day it shows the tithi, nakshatram,
Kollavarsham date, lunar (amanta) month, moon phase, and observances.

Single page, no framework, built for both desktop and mobile: a month grid on
wide screens, a day-by-day list on phones. Tap any day for the full view.

## Files

```
index.html    app shell: loads Google Fonts, app.css, app.js
app.js        vanilla JS, no dependencies
app.css       all styles
about.html    about page
_headers      Cloudflare Pages cache rules
404.html      fallback for unknown paths
data/
  index.json  { months: [...], build: "<id>" }, read first
  YYYY-MM.json one file per month
```

## Data

The calendar data is not computed here. It is generated by a separate
codebase (`varsham-data`) from an ephemeris and written out as one JSON file
per month, plus an `index.json` listing the available range. This site reads
those files directly and renders them; it does no calendar math of its own.

To update: regenerate in `varsham-data`, copy its output into `data/`, commit,
push. Cloudflare Pages redeploys on push.

## How it works

`app.js` fetches `data/index.json` for the month range and a build id, then the
JSON for the month in the URL hash (`#/2026-01`, defaulting to the current
month). Month files are requested with `?v=<build id>`, so a deploy busts the
cache. The grid and list share one markup tree; the switch is a media query.
The day view is a native `<dialog>`.
